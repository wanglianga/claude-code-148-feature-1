# 社区新生儿上门访视 · 黄疸记录与复查随访系统

面向社区护理场景的全栈演示应用：产妇出院后，社区护士上门访视新生儿，记录黄疸、体重、喂养、脐带、大小便与产妇恢复情况；系统按**出生天数 + 黄疸值 + 体重变化 + 喂养次数 + 排便颜色 + 产妇恢复 + 家庭照护能力**综合评估风险，自动生成复查、转诊、母乳指导、电话随访等随访事项并跟踪闭环。**黄疸接近转诊阈值时走专门的临界值复查闭环**：记录测量部位/设备编号/喂养情况/医生建议 → 家属选择次日复测、当天去儿科或居家观察（生成复查提醒与书面风险告知）→ 次日复测生成明确任务（指定护士+携带设备、复测前提醒家属备喂养排便记录）→ 家属再次改约自动升级社区医生（电话干预/建议直接就诊）→ 复测黄疸升高自动生成**带前一天记录与变化趋势的转诊单**。家属端可查看护理建议、复查时间与风险说明，补充出生证明/出院小结/喂养记录，发起线上咨询与改约。护士上门现场网络不稳定时，访视先存**本地草稿**，回到社区后在同步中心**幂等补齐**。

## 功能与角色

| 角色 | 功能 |
| --- | --- |
| **护士**（移动端优先） | 工作台（未访视家庭/异常黄疸/复测待处理/改约升级/待闭环）、预约管理（改约、标记未开门）、母婴档案（访视/测量/照片/建议/复查/转诊/材料/咨询/时间线同档管理）、访视记录表单（实时风险预评估、临界值四项必录、设备故障手工记录、拍照上传）、**黄疸临界值复测中心**（代家属登记选择、安排护士+设备、复测前准备提醒、开始复测、转诊单就诊反馈）、**离线草稿与同步中心**、随访闭环处理、回复线上咨询 |
| **社区医生** | 随访决策台：按档案聚合待处理事项，综合随访记录决定**复查 / 转诊 / 电话随访 / 母乳指导 / 继续观察**；**处理复测再次改约的升级任务**（电话干预劝说复测 / 建议直接就诊 / 继续观察） |
| **家属** | 查看护理建议、复查时间、风险说明；**黄疸临界值时三选一：次日复测 / 当天去儿科 / 居家观察**；查看复测任务（上门护士、设备编号、时间）与喂养排便准备提醒、签收风险告知；**查看复测升高后自动生成的转诊单与变化趋势**；上传出生证明/出院小结/喂养记录；发起线上咨询；申请改约 |

已覆盖的异常场景：家庭临时改约、家属不愿开门（未开门→再次预约事项）、**黄疸接近阈值（临界值：测量部位/设备编号/喂养/医生建议必录 + 家属三选择 + 复测任务 + 风险告知 + 再改约升级 + 升高转诊单）**、黄疸达阈值直接转诊、婴儿体重下降（>7%/>10% 分级）、产妇情绪异常、社区设备故障（手工记录标记+复测提醒）、家长线上咨询、离线草稿回社区后同步。

## 技术栈

- **前端**：React 18 + TypeScript + Vite，状态管理用 **Zustand**（Pinia 是 Vue 生态的状态库，无法用于 React；Zustand 提供与 Pinia 相同的 define-store 范式，含 localStorage 持久化）。移动优先响应式布局，适配护士上门现场操作。
- **后端**：Node.js + Express，SQLite（better-sqlite3）文件库，首次启动自动建表并写入演示数据。
- **风险引擎**：`server/risk.js` 与 `client/src/risk.ts` 同构——表单实时预评估与服务端落库结论一致。

## 一键启动（Docker）

```bash
docker compose up --build
# 打开 http://localhost:8080
```

- 单容器交付：多阶段构建前端 → 后端托管静态页 + REST API + SQLite 初始化。
- 数据持久化在命名卷 `nbv-data`（删除容器不丢数据）；删除卷后重启可重置演示数据。
- 国内网络构建可指定镜像源：`NPM_REGISTRY=https://registry.npmmirror.com docker compose up --build`

## 本地开发

```bash
npm run install:all     # 安装 server 与 client 依赖
npm run dev:server      # 终端1：后端 http://localhost:8080（自动建库+种子数据）
npm run dev:client      # 终端2：前端 http://localhost:5173（/api 代理到 8080）
```

生产模式本地运行：`npm run build && npm start`，然后访问 http://localhost:8080 。

## 风险判定规则（`server/risk.js`）

- 经皮胆红素按出生日龄分档阈值（µmol/L）：≤1 天 137 / 2 天 205 / 3 天 257 / ≥4 天 291；**达阈值→危急+转诊**，**距阈值 ≤34→接近阈值（临界值）**。
- **临界值复查闭环**（`server/service.js`）：临界值访视必须补录**测量部位、设备编号、喂养情况、医生建议**，提交后不直接排预约，而是生成「待选择」复查任务，由家属选择：
  - **次日复测** → 任务进入「待安排」→ 护士明确**哪名护士携带哪台设备、何时上门**（生成复查预约）→ 复测前**提醒家属准备 24h 喂养与排便记录** → 复测访视自动关联任务并与前日读数比对：**升高（或达阈值）→ 生成转诊单**，携带前一天胆红素/部位/设备/体重/喂养/排便与医生建议供医院判断趋势；未升高 → 完成并继续观察。
  - **当天去儿科** → 登记转诊随访事项，等待就诊反馈。
  - **居家观察** → 生成次日复查提醒 + 书面**风险告知**（喂养指导、黄疸观察、红旗症状：黄染加重/嗜睡拒奶/尖叫抽搐/白陶土便等）+ 次日电话随访；家属之后仍可改选。
  - 复测预约被**家属再次改约** → 任务计数 +1 并**自动升级社区医生**，由医生判断**电话干预**（劝说按时复测）、**建议直接就诊**（转转诊事项）或继续观察。
- 体重较出生下降 **>10%→危急+转诊+母乳指导**，**>7%→高风险+母乳指导+复测**。
- 喂养 <8 次/日、白陶土色大便（危急转诊）、脐带渗血/化脓、嗜睡、产妇情绪低落/异常、伤口红肿渗液、家庭照护薄弱等均参与分级；设备故障手工记录强制复测提醒。
- 结论输出：风险等级（低/中/高/危急）+ 是否复查/转诊/母乳指导/电话随访 + 自动生成护理建议（家属端可见，护士可修改）。

## 主要 API

`POST /api/auth/login` · `GET /api/dashboard` · `GET/POST /api/appointments`（`/reschedule`[家属改约复测自动升级]、`/no-show`）· `GET /api/archives`（filter: unvisited/jaundice/maternal/unclosed）· `GET /api/archives/:id`（含 recheckTasks/referrals）· `POST /api/visits`（`/assess` 预评估；临界值四项必录）· `POST /api/sync/visits`（离线幂等同步）· `GET /api/followups`（`/close`、`/decide`）· **`GET /api/rechecks`（`/:id`、`/choice` 家属三选择、`/assign` 护士+设备、`/remind` 准备提醒、`/doctor-decide` 升级判断）** · **`GET /api/referrals`（`/:id/visited` 就诊反馈）** · `GET /api/nurses` · `GET /api/family/overview` · `POST /api/documents` · `POST /api/consults`（`/reply`）
